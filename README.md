# Pullcord

Mapa público de los poderes privilegiados de protocolos DeFi en Stellar: quién es el admin de cada contrato, si es una sola llave o un multisig (y su umbral), si el contrato se puede actualizar o pausar, si usa un executable externo, y alertas cuando cambia el código (wasm) o el admin. Solo hechos, cada uno con link a su fuente. Nunca una calificación, nunca una auditoría, nunca consejo de inversión.
